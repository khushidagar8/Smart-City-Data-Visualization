# Smart City Data Visualization

## About
This project is a basic Smart City visualization project created using Python and Matplotlib. It focuses on representing city-related information through graphs and charts.

## Features
- Graphical data representation
- City-related visualization
- Charts using Matplotlib
- Basic Python programming

## Technologies Used
- Python
- Matplotlib

## Purpose
The purpose of this project is to learn data visualization and understand how graphs can help represent information about a city.

## Learning Outcomes
- Creating graphs using Matplotlib
- Understanding data visualization
- Practicing Python programming
- Presenting data visually

## Project Status
Beginner project – basic visualization completed.
